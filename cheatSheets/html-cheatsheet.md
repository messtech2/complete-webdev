```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Page Title</title>
</head>
<body>
    <!-- Content Here -->
</body>
</html>


```

# Common Tags

| Tag          | Usage       | Example                          |
|--------------|-------------|----------------------------------|
| `<h1>`-`<h6>`| Headings    | `<h1>Title</h1>`                 |
| `<p>`        | Paragraph   | `<p>Text here</p>`               |
| `<a>`        | Link        | `<a href="url">Link</a>`         |
| `<img>`      | Image       | `<img src="image.jpg">`          |
| `<ul>`/`<ol>`| Lists       | `<li>Item</li>`                  |
| `<table>`    | Table       | `<tr><td>Cell</td></tr>`         |
| `<form>`     | Form        | `<input type="text">`            |

# Semantic HTML

| Tag         | Usage                              |
|-------------|------------------------------------|
| `<header>`  | Introductory content or banner     |
| `<nav>`     | Navigation links                   |
| `<main>`    | Main content of the page           |
| `<section>` | Thematic grouping of content       |
| `<article>` | Independent, self-contained content|
| `<footer>`  | Footer content or information      |
